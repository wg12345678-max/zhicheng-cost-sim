# 智控成本 · 数创价值

**—— 制造企业全流程成本管理虚拟仿真实训（Streamlit 交互版 · 创始人日记体 × 指挥中心 UI）**

依据《西南财经大学天府学院 · 成本管理会计 ACT1415A》课程组《智控成本数创价值 · 设计方案 V5.0》构建。
2026 中国仿真创新应用大赛 · 仿真教学应用赛道 · 虚拟仿真实验设计方向（高教文科·经济管理类）。

## 交互式虚拟仿真实训

- **28 步全流程**：A 情境与参数设定（1–4）→ B 自主设计与决策（5–21，占 60.7%，核心）→ C 风险与博弈（22–25）→ D 产出与复盘（26–28）
- **创始人日记体**：每步以「第 N 天，投资人 / 供应商 / 财务经理 / 管理会计师说…」开场，代入感强；角色随流程从成本会计→车间核算员→财务经理→管理会计师进阶
- **指挥中心 UI**：纯黑底 + 霓虹绿、28 步网格监控导航、四指标霓虹卡片，营造紧迫 · 掌控感
- **每一步做决策**（采购谈判、领料排产、人工排班、费用分摊、约当产量、品种/分批/分步法、两法对比、量本利、标准成本、差异分析、作业成本、动因博弈、责任考核、方案竞标、风险应对、经营决策…），**实时刷新四大指标**：单位产品成本 / 经营利润 / 成本偏离指数 / 责任绩效分（算账闭环）
- **有试错代价**：内含 **红线机制**（成本造假 / 虚增存货 / 责任甩锅，首次警告扣 30 分 + 重做）、**随机风险事件**、**AI 四维判分**（创新/可操作/成本影响/业财融合）
- **过程可追溯**：每步决策存档，完成后生成**个人实验报告**（过程记录表 + 能力画像雷达 + 终结性评分）

## 核心算账引擎（方案 3.3 节，已用标准例题验算）

```
材料单位成本 = 直接材料总额 / (完工产品数量 + 材料约当产量)
加工单位成本 = 加工成本总额 / (完工产品数量 + 加工约当产量)
单位产品成本 = 材料单位成本 + 加工单位成本
完工产品成本 = 完工数量 × 单位产品成本
月末在产品成本 = 材料约当×材料单位成本 + 加工约当×加工单位成本
经营利润 = 售价×完工数量 − 完工产品成本
成本偏离指数 = 实际单位成本 / 标准成本 × 100%
责任绩效分 = 95 − (|偏离指数 − 100|) × 2
```
