# 智控成本 · 数创价值

**—— 制造企业全流程成本管理虚拟仿真决策实训（Streamlit 演示版）**

依据《西南财经大学天府学院 · 成本管理会计 ACT1415A》课程组《智控成本数创价值 · 设计方案 V4.0》构建。

## 功能板块

- **作品概览**：作品定位、四层系统架构、技术选型
- **算账引擎 · 交互演示**：核心算账引擎实时计算四大指标（单位产品成本 / 经营利润 / 成本偏离指数 / 责任绩效分），可拖动参数观察变化
- **标准例题验算**：复现方案 3.4 节标准例题手工验算
- **28 步实验流程**：模块 A/B/C 全链路 28 步交互实验设计
- **红线机制与风险事件**：两次触发制红线 + 5 类风险事件池 + AI 降级方案
- **参数边界测试**：7 类极端输入场景（7/7 通过），支持现场复算
- **判断标准自检**：17 条自检清单
- **参考文献与附录**：6 条参考文献、参数校准记录、作品介绍

## 核心算账引擎（方案 3.3 节）

```
材料单位成本 = 直接材料总额 / (完工产品数量 + 材料约当产量)
加工单位成本 = 加工成本总额 / (完工产品数量 + 加工约当产量)
单位产品成本 = 材料单位成本 + 加工单位成本
完工产品成本 = 完工数量 × 单位产品成本
月末在产品成本 = 材料约当×材料单位成本 + 加工约当×加工单位成本
经营利润 = 售价×完工数量 − 完工产品成本
成本偏离指数 = 实际单位成本 / 标准成本 × 100%
责任绩效分 = 95 − (|偏离指数 − 100|) × 2
```
